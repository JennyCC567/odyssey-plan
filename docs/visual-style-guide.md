# 人生罗盘视觉风格规范

本规范用于后续延展“从八字命理，到红点探索，再到奥德赛计划”的产品界面。整体目标不是做玄学工具，也不是做效率型后台，而是营造一次安静、克制、有仪式感的人生推演。

## 核心气质

- 留白：让问题、镜像句和诊断结论成为画面中心，不用密集组件证明功能丰富。
- 哲学感：文字像一段内在提问或短篇手稿，避免营销话术和强刺激表达。
- 东方水墨：使用墨色、淡雾、水面、圆形命盘、轻舟等隐喻，但不堆叠八卦、龙纹、符咒等直白符号。
- 希腊典雅：使用米白石色、细线、柱式比例、航线、坐标、岛屿/海图隐喻，但不直接堆神庙插画。
- 中西融合：东方负责“气韵与留白”，希腊负责“秩序与航行”。两者都应克制地存在于空间、比例和隐喻中。

## 色彩系统

主色应接近纸张、石膏、墨色和微弱金光。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 纸面背景 | `#f6f3ec` | 米白纸张，不用纯白。 |
| 石色面板 | `#eee8dc` | 古希腊石材和羊皮纸气质。 |
| 主文字 | `#24211d` | 接近墨色。 |
| 次文字 | `#706a61` | 温和灰褐，降低信息压迫。 |
| 极淡线条 | `#d8d0c3` | 只用于空间分隔。 |
| 深墨按钮 | `#25231f` | 主要行动，沉稳而非彩色。 |
| 金色点缀 | `#c8a64a` | 只用于进度、焦点、航线，不大面积使用。 |
| 警示纸黄 | `#fbf0d7` | 用于“不确定，需要补问”等温和提示。 |

禁止使用大面积高饱和紫色、蓝色、橙色渐变；避免明显的科技感霓虹。

## 字体与文字

- 中文标题优先使用宋体气质：`Songti SC`、`STSong`、`Noto Serif SC`、系统 serif。
- 正文使用清晰黑体：`PingFang SC`、`Microsoft YaHei`、Arial。
- 标题字重不宜过粗，字号可以大，但行距要松。
- 正文行高建议 `1.7-1.9`，让内容像手稿阅读，而不是表单说明。
- 英文只作小标签或副标题，使用小写或小型大写的航海/档案感，如 `PATHFINDER`、`ODYSSEY MAP`。

## 布局原则

- 一屏一个主任务：出生信息、单个问题、镜像回应、诊断报告、三版计划都应该有明确主角。
- 卡片少用：卡片只用于重复条目、报告段落、计划路径。不要把页面切成很多后台式小模块。
- 侧栏像“航海/命盘目录”，主区域像“纸面手稿”。
- 保留宽边距和垂直节奏，尤其在问题页，不要把输入框、标签、说明挤在一起。
- 桌面端可以双栏，但右栏应轻、淡、像注释；移动端以纵向叙事为主。

## 图形语言

- 背景可使用极淡水墨晕染、半透明圆、海面曲线、轻舟剪影、航线点。
- 圆形代表命盘/镜面，细线代表航路/推理链。
- 希腊元素只通过石色、柱式竖线、比例和坐标感体现。
- 装饰透明度要低，通常在 `0.04-0.14` 区间，不能干扰阅读。

## 组件规则

- 主按钮：深墨底、白字、胶囊或 8px 内圆角，像“入海/继续航行”的动作。
- 次按钮：纸面底、细线边框、墨色文字。
- 输入框：纸面或半透明白底，边框极淡，聚焦时用金色或墨色细阴影。
- 选项：宽松的胶囊或纸条，轻阴影；选中态用深墨，不用彩色高亮。
- 进度：细线，不用粗进度条。金色只作为一小段光标或航线。
- 报告：像卷轴/手稿，标题强，正文长行距，减少图标。

## 动效方向

- 过渡应像水面浮现：淡入、轻微上移、慢速背景漂移。
- 避免弹跳、强缩放、霓虹闪烁。
- 生成中、镜像回应、章节转场可以使用一句极淡文字居中出现。

## 产品场景映射

- 轻命理开场：像站在岸边看命盘，给用户好奇心，但不下结论。
- 红点十二问：像问心，不提前给类型标签；问题是主角，证据标签是辅助。
- 三问一镜像：像水面反射出一句判词，短、轻、留白大。
- 诊断草案：像共读一份手稿，有证据、有不确定、有修订窗口。
- 奥德赛计划：像展开三条航线，每条都要有资源、风险和第一步试航。

## 禁忌

- 不做玄学恐吓、命定论、神秘符号堆叠。
- 不做典型 SaaS dashboard：过多卡片、彩色状态块、密集图标都会破坏气质。
- 不把红点类型过早做成醒目的身份标签。
- 不用“你一定适合”“命中注定”这类定论式表达。
